# Оформление SoundSense

Оформление состоит из трёх независимых осей. В настройках каждая имеет собственный выбор пресета и свой JSON-пакет.

| Ось | Содержимое | Встроенные пресеты |
|---|---|---|
| Стиль | Шкалы формы, типографики, плотности и оформления поверхностей | Стандарт, Ретро, Плоский |
| Цвета | Палитра и признак светлой/тёмной схемы | Обложка, Аметист, Серебро, Лайм, Золото, Монохром, AMOLED, Высокий контраст, Свой |
| Анимации | Эффекты, длительность и easing для групп | Плавный, Пружинный, Ретро, Минимум, Выкл |

Любые сочетания допустимы: например, стиль «Ретро», цвета «Золото» и анимации «Пружинный». В стиле нет цветов или длительностей, в палитре нет радиусов, анимации не меняют палитру или плотность. Старая общая настройка «Тема» заменена этими тремя пунктами.

## Общая схема и загрузка

Единственный реестр — `src/ui/appearance/schema.ts`. Он определяет разрешённые ключи, типы, значения по умолчанию, числовые диапазоны и списки эффектов. Валидаторы, загрузчик, CSS-переменные и редакторы опираются на этот реестр. CSS-производные и константы геометрии находятся в `src/ui/appearance/tokens.css`. При расширении формата сначала добавляют описание в схему, затем использование в интерфейсе и проверку.

Все пакеты имеют `version: 1` и непустое `name` длиной до 80 символов. Объект содержимого (`tokens`, `palette` или `groups`) обязателен, но может быть пустым. Неполный пакет наследует отсутствующие значения от значений по умолчанию **своей оси**. Это не последовательное накопление произвольных изменений: корректный новый пакет полностью определяет итог этой оси после дополнения defaults.

Проверка атомарна. Неизвестный ключ, неподдерживаемая версия, неверный тип, нечисловое/бесконечное число, выход за диапазон или ключ другой оси отклоняет весь пакет. JSON не может добавлять произвольные CSS-свойства, `url()`, выражения или исполняемый код. Ошибка показывается при импорте и содержит причину; интерфейс сохраняет последний валидный пакет.

Изменение пакета не перезагружает приложение и не меняет очередь, состояние play/pause, историю навигации или обработчики жестов. Загрузчик выставляет только переменные оформления: реальные `--inset-*` и измеренный доком `--dock-height` ему не принадлежат.

## Пакет цветов

Файлы встроенных палитр находятся в `src/ui/appearance/colors/`. Значения — только `#RRGGBB` или `#RRGGBBAA`; в восьмизначной записи альфа находится **в конце**, как в CSS.

```json
{
  "version": 1,
  "name": "Моя палитра",
  "scheme": "dark",
  "palette": {
    "mainBg": "#101010",
    "accent": "#f4f4f2",
    "text": "#f4f4f2",
    "textOnAccent": "#141414"
  }
}
```

`scheme` принимает `dark` или `light`; при пропуске наследуется `dark` из «Монохром». Он задаёт CSS `color-scheme` и цвет значков системных панелей Android, включая свои и динамические палитры. Выбор стиля не определяет яркость системных значков. Эффективная схема доступна также как `data-color-scheme` у корневого элемента.

| Роль | Назначение |
|---|---|
| `mainBg` | Основной фон приложения |
| `barBg` | Базовый фон навигации |
| `cardBg` | Карточки и поверхности |
| `cardHover` | Состояние поверхности при взаимодействии |
| `bgOverlay` | Затемнение под шторкой |
| `border`, `borderLight` | Обычные и выделенные границы |
| `accent` | Основные действия, активные состояния |
| `text` | Основной текст |
| `textMuted` | Второстепенный текст |
| `textOnAccent` | Текст на акцентной поверхности |
| `accentMutedText` | Дополнительный приглушённый акцент |
| `danger`, `warning`, `success` | Семантические состояния |

Это те же имена ролей, что в палитре Quickshell пользователя. JSON-палитра не содержит готовых градиентов, теней или CSS-строк. Уровни поверхностей, градиенты плеера/дока, затемнение обложки, цвета волны и тени вычисляются из этих ролей через `var()` и `color-mix()`. Сила тени и blur задаются стилем. Поэтому изменение `mainBg` влияет и на градиенты, а смена палитры не оставляет цвета предыдущего пресета.

Цветовые переменные регистрируются через `CSS.registerProperty` с `syntax: '<color>'`. Переход палитры использует длительность и easing группы `general`.

Встроенные цвета:

- **Монохром** (`mono`) — тёмная палитра по исходным макетам.
- **Аметист** (`amethyst`) — тёмный фиолетовый фон и фиолетовый акцент.
- **Серебро** (`silver`) — стальные поверхности и светлый акцент.
- **Лайм** (`lime`) — графитовые поверхности и салатовый акцент.
- **Золото** (`gold`) — тёмный красно-коричневый фон и золотой акцент.
- **AMOLED** (`amoled`) — чёрный фон, почти чёрные поверхности и светлый акцент.
- **Высокий контраст** (`high-contrast`) — чёрно-белая палитра с контрастными границами.
- **Обложка** (`cover`) — динамическая палитра на базе «Монохром»: SVG заглушки с неизменяемыми монохромными остановками растрируется на canvas 32 × 32 и усредняется. Пока SVG не доступен или извлечение не удалось, используется детерминированный fallback по `seed` и `variant`. База не берётся из уже применённой динамической палитры, поэтому повторный выбор не накапливает цветовой сдвиг. Смена трека запускает тот же плавный переход палитры.

Контраст основного/второстепенного текста и текста основных действий во встроенных палитрах проверяется тестами на отношение не ниже 4.5:1. Для «Обложки» проверяются несколько детерминированных мок-обложек. Собственная палитра позволяет менять роли вручную; выбирайте значения, при которых текст остаётся читаемым на соответствующей поверхности.

## Пакет стиля

Встроенные стили находятся в `src/ui/appearance/styles/`.

```json
{
  "version": 1,
  "name": "Мой стиль",
  "tokens": {
    "radiusS": 4,
    "radiusM": 8,
    "radiusL": 12,
    "blurNav": 0,
    "shadowStrength": 0,
    "listDensity": 1
  },
  "suggest": {
    "colors": "mono",
    "motion": "smooth"
  }
}
```

Числовые размеры задаются числами, а не строками с `px`. CSS-единицы добавляет генератор по схеме. Редактор и валидатор используют одни диапазоны.

| Токены | Что задают |
|---|---|
| `space1` … `space8` | Шкала отступов |
| `radiusS`, `radiusM`, `radiusL`, `radiusXl`, `radiusFull` | Шкала радиусов |
| `fontBody`, `fontDisplay`, `fontMono` | Семейства шрифтов с локальными запасными вариантами |
| `fontXs`, `fontS`, `fontSm`, `fontM`, `fontBodySize`, `fontL`, `fontXl`, `font2xl`, `font3xl`, `fontHero`, `fontLyrics` | Шкала размеров текста; `fontBodySize` — число, `fontBody` — семейство шрифта |
| `weightNormal`, `weightMedium`, `weightSemibold`, `weightBold` | Начертания |
| `borderWidth`, `focusWidth` | Толщина рамок и клавиатурного фокуса |
| `chromeBorders` | Рамки у карточек и кнопок: 0 или 1 |
| `blurNav`, `blurArt` | Размытие поверхностей |
| `opacityDisabled`, `opacityHover`, `opacityPressed`, `opacityMuted`, `opacityArt`, `opacityNoise`, `opacityRing`, `opacityLine` | Прозрачности состояний и декоративных слоёв |
| `shadowStrength` | Сила теней, без хранения цвета |
| `listDensity` | Плотность строк списка |

Диапазоны размеров и радиусов указаны в CSS px; остальные числа безразмерны, если не оговорено отдельно:

| Токены | Диапазоны |
|---|---|
| `space1` … `space8` | 2–12, 4–20, 6–26, 8–32, 10–38, 12–44, 14–48, 16–56 |
| `radiusS`, `radiusM`, `radiusL`, `radiusXl`, `radiusFull` | 0–24, 0–32, 0–48, 0–64, 0–999 |
| `fontXs`, `fontS`, `fontSm`, `fontM`, `fontBodySize` | 10–20, 10–22, 11–24, 12–26, 12–28 |
| `fontL`, `fontXl`, `font2xl`, `font3xl`, `fontHero`, `fontLyrics` | 14–30, 16–34, 18–40, 22–46, 24–48, 18–42 |
| `weightNormal`, `weightMedium`, `weightSemibold`, `weightBold` | 100–900, шаг 100 |
| `borderWidth`, `focusWidth` | 0–3, 1–4 |
| `chromeBorders` | 0 или 1; Стандарт — 0, Ретро и Плоский — 1 |
| `blurNav`, `blurArt` | 0–40, 0–8 |
| `opacityDisabled`, `opacityHover`, `opacityPressed`, `opacityMuted` | 0.2–0.8, 0–0.4, 0–0.5, 0.3–1 |
| `opacityArt`, `opacityNoise`, `opacityRing`, `opacityLine` | 0.2–1, 0–0.4, 0–0.6, 0.1–1 |
| `shadowStrength`, `listDensity` | 0–0.6, 0.85–1.3 |

Семейства шрифтов — локальный список длиной 1–160 символов: имена, кавычки, запятые, пробелы и дефисы. CSS-функции и ссылки в этом поле запрещены.

Размеры конкретных элементов — обложек, кнопок плеера, навигации — остаются константами CSS, вычисленными из шкал. Они не добавляются в пакет. Минимальная область касания сохраняется при плотном стиле. Высота виртуализированной строки согласована с плотностью и размером шрифта.

«Стандарт» использует скруглённые карточки, гротеск, полупрозрачную навигацию, blur и мягкие тени. «Ретро» обнуляет радиусы, использует `JetBrains Mono` с системным моноширинным запасным шрифтом, рамки, плотные строки, без blur и мягких теней. «Плоский» использует небольшие радиусы, увеличенные отступы и тонкие границы без теней и blur. Установка шрифтов или обращение к удалённому серверу не требуется.

`suggest` необязателен и содержит только известные идентификаторы встроенных цветов/анимаций. Он не объединяет оси и не отменяет ручной выбор. Для «Стандарта» рекомендация — `mono` + `smooth`, для «Ретро» — `retro90` + `retro`. Неизвестный идентификатор отклоняет пакет стиля.

## Пакет анимаций

Встроенные пакеты и общий runtime эффектов находятся в `src/ui/appearance/motion/`.

```json
{
  "version": 1,
  "name": "Мои анимации",
  "groups": {
    "general": { "effect": "fade", "duration": 160, "easing": "standard" },
    "title": { "effect": "typewriter", "duration": 280, "easing": "steps(6)" },
    "waveform": { "effect": "sweep", "duration": 220, "easing": "linear", "progress": "stepped" }
  }
}
```

Каждая группа принимает только свои эффекты:

| Группа | Применение | Эффекты | Длительность, мс |
|---|---|---|---|
| `general` | Экраны, шторки, нажатия, переход палитры | `fluid`, `color-spread`, `listen-flight`, `liquid-tabs`, `tab-circle`, `depth`, `cascade`, `crt`, `play-morph`, `like-sparks`, `fade`, `slide`, `scale`, `none` | 0–1200 |
| `player` | Открытие/закрытие полного плеера | `shared`, `drop`, `slide-up`, `expand`, `fade` | 0–1500 |
| `title` | Название и исполнитель в полном и мини-плеере | `fade`, `slide-up`, `blur`, `typewriter`, `split-flap`, `decipher`, `none` | 0–1500 |
| `cover` | Смена обложки | `stack`, `goo`, `crossfade`, `slide`, `zoom`, `none` | 0–1500 |
| `lyrics` | Смена и подсветка строки текста | `fade`, `scale`, `blur`, `fill`, `none` | 0–1500 |
| `waveform` | Появление волны | `morph`, `grow`, `sweep`, `none` | 0–1200 |

У `waveform` также есть `progress`: `smooth` или `stepped`; в других группах этого ключа нет. `easing` принимает `standard`, `emphasized`, `spring`, `linear`, `steps(N)` с целым N от 2 до 12 или массив `[x1, y1, x2, y2]` для cubic-bezier: x — от 0 до 1, y — от −2 до 2. Произвольная строка CSS отклоняется. Для частичной группы допускается задать только один параметр; остальные берутся из группы «Плавного».

«Плавный» — стопка, перетекание волны, перелёт элементов и плавные взаимодействия; «Пружинный» — пружинные переходы, scale при нажатии и expand у плеера; «Ретро» — табло/ЭЛТ и ступенчатый прогресс; «Минимум» — очень короткие переходы; «Выкл» — нулевая длительность всех групп. Фиксированный список эффектов не расширяется произвольным именем даже в своём пакете.

В настройках анимаций выбирается общий пресет и отдельное переопределение каждой группы: «Как в общем» или другой пресет. Кнопка ▶ воспроизводит выбранную группу на образце. Скорость 0.5×–2× применяется ко всем группам: 2× проигрывает эффект вдвое быстрее, 0.5× — вдвое медленнее.

Runtime выставляет `--motion-<group>-duration`, `--motion-<group>-easing` и `data-motion-<group>` с эффективным эффектом. Компоненты указывают группу и повод повторить переход; определения эффектов централизованы. Старых `--motion-fast/normal/slow` в интерфейсе нет. Используются transform и opacity; filter применяется в `blur` и `goo`. При `hardwareConcurrency <= 4` эффект `blur` подменяется на `fade`, а `goo` на `stack`, остальные группы и настройки сохраняются.

## Приоритеты и системное уменьшение движения

«Подбирать цвета и анимации под стиль» включено по умолчанию. Рекомендации применяются отдельно для каждой оси, если пользователь не закрепил её вручную.

| Значение | Приоритет |
|---|---|
| Цвета | Ручной выбор → рекомендация стиля при включённом подборе → Обложка |
| Анимация группы | Ручное переопределение группы → ручной общий пресет → рекомендация стиля при включённом подборе → Плавный |

Системное `prefers-reduced-motion: reduce` выбирает «Минимум», пока пользователь не выбрал пресет анимаций вручную. Ручные настройки групп и общего пресета сохраняются; автоматическое изменение стиля не подменяет их.

Рядом с выбором показывается источник значения: «по стилю» или «вручную». «Вернуть по стилю» снимает ручное закрепление соответствующей оси. Переопределение одной группы не закрепляет другую группу. Отключение подбора не удаляет сохранённые ручные значения.

## Выбор, свои пакеты и сброс

Экран выбора **стиля** показывает мини-экран каждого пресета в текущих цветах. Экран выбора **цветов** показывает каждую палитру в текущем стиле. Выбор применяется сразу; активная карточка отмечена.

Для каждой оси доступен пункт «Свой»:

1. Выберите встроенный пресет как основу.
2. Перейдите к своему пакету соответствующей оси.
3. Измените значения в редакторе или импортируйте JSON из файла/поля вставки.
4. Корректное изменение сразу видно в интерфейсе. Ошибочный ввод не заменяет последний рабочий пакет.
5. Экспортируйте текущий пакет в JSON. «Сбросить» возвращает значения исходного пресета своего пакета.

Редактор цветов содержит все роли: образец, HEX и системный выбор цвета. Альфа при необходимости задаётся в HEX. Редактор стиля показывает основные радиусы, шрифты и размер текста, рамки, blur и плотность. Для анимаций доступны общий пакет, группы и образцы эффектов. Все подписи есть на русском и английском.

Сброс своего пакета отличается от общего сброса настроек: первый возвращает его основу, второй восстанавливает начальные значения настроек. Пакеты сохраняются через тот же `SettingsApi`, что остальные настройки. При недоступном localStorage они остаются в памяти текущего запуска.

Экспорт вызывает общий `FilesApi.saveJson(filename, text)`. В браузере он создаёт JSON Blob и запускает загрузку файла. В Android существующий локальный Capacitor-плагин `SystemUi` открывает системный диалог Storage Access Framework (`ACTION_CREATE_DOCUMENT`, MIME `application/json`). Пользователь выбирает имя и место, затем документ записывается в UTF-8 через `ContentResolver` в полученный `content:` URI; дополнительные разрешения хранилища не запрашиваются. Отмена возвращает `cancelled` и не считается ошибкой или успешным сохранением. Некорректный JSON и документ больше 100 000 UTF-8 байт отклоняются до открытия диалога. Предлагаемое имя очищается от разделителей пути и управляющих символов и получает расширение `.json`. Ошибка провайдера сохраняет редактируемый пакет на экране, чтобы экспорт можно было повторить. Работа системного диалога на физическом устройстве требует отдельной проверки.

## Адаптер Quickshell

`fromQuickshellPack(json)` принимает разобранный пакет Quickshell с полями `version/skin/layout/palette/tokens`. Он читает только `palette`, остальные поля не переносятся в стиль или анимации SoundSense.

Qt записывает восьмизначный цвет в порядке `#AARRGGBB`. Адаптер переводит его в CSS-порядок `#RRGGBBAA`; шестизначные цвета остаются без перестановки. Результат проходит обычный валидатор пакета цветов. Неизвестная роль или неверный цвет возвращает ошибку. У Quickshell нет `scheme`: адаптер определяет его по яркости импортированного `mainBg`, учитывая его альфу поверх базового фона. Светлая тема Quickshell поэтому возвращает светлый пакет SoundSense.

Проверка использует сохранённую копию пользовательского `~/.config/quickshell/ui/theme.json` в тестовой фикстуре. Тест не обращается к живому файлу. Адаптер не наблюдает dotfiles, не запускает Quickshell и не меняет рабочий стол. Пресет «Рабочий стол», live-подключение и Electron относятся к следующему этапу.

## Проверки и снимки

```sh
npm run check
npm run lint
npm test
npm run test:ui
npm run build
```

Модульные тесты проверяют частичные/некорректные пакеты всех осей, сохранение последнего валидного состояния, независимость осей, все встроенные пакеты и сочетания стиль × цвета, контраст, Qt-адаптер и приоритеты ручных/автоматических настроек. Браузерные сценарии проверяют выбор, редакторы и сохранённые регрессии раскладки/жестов.

`scripts/check-colors.mjs` разрешает цветовые литералы только в JSON-пакетах `src/ui/appearance/colors/`. Он проверяет также производные поверхности, градиенты и тени. `currentColor`, `var()` и `color-mix()` от ролей палитры допустимы; перенос цветового литерала в CSS-переменную вне палитры не обходит lint.

Скриншоты оформления находятся в `docs/screens/appearance/`: главная и плеер для стилей в «Монохром», палитр в «Стандарт», сочетание «Ретро + Золото», выбор стиля/цветов и настройки анимаций. Viewport — 412 × 915, DPR 2, имитация insets сверху 48 px и снизу 24 px.

Браузерная проверка не подтверждает частоту кадров и поведение системных панелей на физическом Android. Плавность `blur` и `expand` и живые WindowInsets нужно проверить на подключённом телефоне отдельно. Автоматическая установка эмулятора в эту работу не входит.

## Дополнение UX-2

По умолчанию выбрана «Обложка». Без текущего трека используется её базовая палитра «Монохром». Стиль «Ретро» рекомендует «Лайм»; ручной выбор цвета сохраняет приоритет. У карточек выбора есть образцы основных ролей. Светлая схема остаётся доступна в своём пакете.

Одноразовый `node scripts/import-hyprtheme-palettes.mjs [корень-источников]` читает только литералы `Colors.qml` или `palette` из `theme.json`. QML не исполняется. Генерация проходит через общий `fromQuickshellPack`; Qt-альфа преобразуется, `mainBg` смешивается с чёрным до непрозрачности. Во время работы приложения внешние файлы тем не читаются. Список адресных коррекций — `docs/palette-corrections.json`.

Группа `general` с эффектом `fluid` включает контекстные взаимодействия из образца; отдельные эффекты можно выбирать в своём пакете. Смена формы волны рисуется интерполяцией самих высот, без смены всего canvas одним кадром. При первом расчёте столбики растут слева направо. Сыгранный canvas раскрывается по точной доле прогресса, включая часть столбика; перемотка не интерполируется с задержкой. Время движется за пальцем.

При склейке длительность визуального перехода берётся из `PlayerState.transition`, в том числе если она больше редакторского диапазона длительности эффекта. Цвета «Обложки» меняются в течение перекрытия. Системное уменьшение движения и выключенные группы сохраняют действие.
