# Репозиторий

В Git лежат исходники, конфиги сборки, `package-lock.json`, Gradle wrapper, тестовые фикстуры, лицензии зависимостей и документация. Зависимости ставятся через `npm ci`.

Ветки:

- `main` — исходный код, документация и каталог плагинов (`plugins/`).
- `releases` — только последние подписанные `stable.json` / `beta.json` и APK. Ветку создаёт и заменяет скрипт выпуска (`npm run release:stable`), руками её не правят. Приложение читает её сами обновления.

Генерируемое (`dist/`, Android `build/`, `artifacts/`), локальный toolchain и секреты (`.release/`, `.env*`, ключи подписи) в Git не попадают — см. `.gitignore`. Публичный ключ обновлений `src/core/update-key.json` нужен приложению и хранится в Git; приватный ключ подписи остаётся только у владельца.

Лицензии зависимостей — в `public/licenses/`.
